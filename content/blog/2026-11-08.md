## Highlights

**Boot and VM fixes.** bootc now lets systemd-repart size the generated root partition ([bootc#2532](https://github.com/bootc-dev/bootc/pull/2532)), skips its fstab editor for a read-only root ([#2615](https://github.com/bootc-dev/bootc/pull/2615)), and creates `/var/lib/systemd` early rather than reordering tmpfiles ([#2628](https://github.com/bootc-dev/bootc/pull/2628)). bcvk fixed removal of libvirt domains with a managed save image ([bcvk#412](https://github.com/bootc-dev/bcvk/pull/412)).

**Broker continuity.** The credential broker gained usage-window persistence across restarts ([praxis-credential-broker#48](https://github.com/cgwalters-bot/praxis-credential-broker/pull/48)) and a fix to keep stale pools from holding the whole grant ([#58](https://github.com/cgwalters-bot/praxis-credential-broker/pull/58)).

**Less JavaScript in shared actions.** The actions repository moved workflow tests that execute no JavaScript to Rust ([actions#156](https://github.com/cgwalters-forge/actions/pull/156)) and made admit and deployment run without Node ([#178](https://github.com/cgwalters-forge/actions/pull/178)). Dispatched reviews are now bound to an expected head and pool ([#198](https://github.com/cgwalters-forge/actions/pull/198)).

**Scheduler request allocation.** agent-board gave stages 2 and 3 a share of requests and refunds for HTTP 304 responses ([agent-board#769](https://github.com/cgwalters-forge/agent-board/pull/769)). It also landed prioritization and rotation of authored work within a pass, without keeping state ([#773](https://github.com/cgwalters-forge/agent-board/pull/773)).
