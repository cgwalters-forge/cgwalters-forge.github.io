cgwalters-forge

Tools for running coding agents in GitHub Actions without handing them the job's credentials. The same host hardening is meant for plain, deterministic CI too: if a technique only helps agent jobs, it isn't done.

Agents in CI

agentic-job

Run a coding agent through ACP as a GitHub Actions job, in the spirit of gh-aw: the agent runs sandboxed, its outputs are validated before anything is written, and every run records its metadata.

agent-board

A GitHub project board as the control plane between a human, a coordinator and sandboxed agents. Work is scheduled from the board, and changes go through safe outputs. Early.

Hardened CI for every job

actions

Shared GitHub Actions, notably secure-host, which hardens a runner before any untrusted step runs. A BPF LSM policy refuses world-write changes as they happen, and an egress policy is available as an opt-in.

secure-hostSource

workflow-compiler

Compile a GitHub Actions job, written in nickel as a privileged setup phase and an unprivileged phase, into a workflow in which no later step can become the runner's user again.
